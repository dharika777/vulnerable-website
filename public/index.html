Broken Object Level Authorization (BOLA)

This system deliberately exposes object-level endpoints (Users, Orders, and Invoices) with zero authentication or authorization checks. Any identity or automated security scanner can freely access, alter, or purge another entity's private records simply by altering object IDs.
